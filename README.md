# ChemEngHub

ChemEngHub is an interactive chemical engineering calculator and simulation tool built using Python and Streamlit which combines chemical engineering theory with Python programming to create calculators and visualisations based on topics covered during my first year of Chemical Engineering.

## Topics couvered

### Fluid Dynamics
- Reynolds Number Calculator
- Pressure Drop Calculator
- Pump Power Calculator
### Heat Transfer
- Heat Duty Calculator
- LMTD Calculator
- Heat Exchanger Area Calculator
### Reaction Engineering
- Arrhenius Equation Calculator
- CSTR Volume Calculator
- PFR Volume Calculator
- Reaction Kinetics Simulator

I created ChemEngHub as a personal engineering project to strengthen my Python programming skills that I developed at university while applying chemical engineering concepts to practical calculations and simulations. The project is kept relatively simple and reflects my own development and understanding of programming and engineering concepts.
